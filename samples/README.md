# Sample Formula Files

Sample Formula files can be imported into Accordbook without replacing your current notebook.

1. Download a Formula JSON file.
2. Open Accordbook.
3. Choose **Import formula**.
4. The Formula is added to your notebook.
5. Duplicate or edit it as needed.

A Formula File shares one formula and adds it to the current Notebook. A Notebook Backup contains the full notebook and **Restore backup** replaces the current notebook.
